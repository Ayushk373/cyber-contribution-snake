## ✨ Features

- 🐍 Animated GitHub contribution Snake
- 🟣 Neon cyber theme
- 🔵 Cyan contribution colors
- 🌙 Dark mode
- ☀️ Light mode
- ⚡ Automatically generated with GitHub Actions
- 🔧 Easy to customize
- 🚀 Free and open source

## 🚀 Use It on Your Profile

### 1. Fork this repository

Click the **Fork** button at the top of this repository.

### 2. Run the workflow

Go to:

`Actions → 🐍 Cyber Contribution Snake → Run workflow`

### 3. Add it to your profile README

Copy:

```html
